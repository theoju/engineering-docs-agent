# What's New

## 2026-06-23T08:20:55.015664+00:00
- PR #135: Three legacy architecture pages — `architecture/index.md`, `architecture/lint-rules.md`, and `architecture/bootstrap-fail-fast.md` — were backfilled with the required agent-authored frontmatter fields (`description`, `source_files`, `last_reviewed`) that the `AGENT_AUTHORED_REQUIRED` contract mandates. These pages predated the contract and caused every nightly page-author edit to them to be silently dropped by Tier-1 frontmatter_schema / description_quality lint, producing partial runs and blocking the CCE-101 auto-merge gate.
- PR #136: The orchestrator's time-budget enforcement now covers the page-author fan-out phase. Previously the CCE-109 soft deadline was checked only at PR admission (early in the run); the page-author loop — up to ~50 Opus dispatches per backlog window — ran unbounded past the deadline, causing the nightly GitHub Actions job to be killed at timeout-minutes: 60. The fix adds a deadline check before each authoring batch (with an at-least-one-progress guarantee so tight budgets still crawl forward), skips the fact-checker loop outright once the deadline expires and flips the PR to `partial` (blocking CCE-101 auto-merge), and skips the gap-detector loop on expiry under the same posture. All three cuts leave the PR open for operator review.
