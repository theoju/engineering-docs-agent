# Release Decision: v0.5.1 (2026-06-09)

**PR:** [#124](https://github.com/theoju/engineering-docs-agent/pull/124)

## What changed

`CHANGELOG.md` was stamped from `[Unreleased]` to `[0.5.1]`, covering 20 post-v0.5.0 commits. The previously-missing `[0.5.0]` section was backfilled at the same time. `plugin.json` had its version field resynchronised from the stale `0.2.0` to `0.5.1`. No behaviour or logic changed; these are artefact-only corrections.

## Why it was needed

v0.5.0 was tagged without a corresponding changelog entry, and `plugin.json` was never bumped after the 0.2.0 era. Tag-pinned host repos pick up the manifest version at the next 07:07 UTC nightly (Clock 2, per `docs/runbooks/release-and-rollback.md`). A mismatched version in `plugin.json` means hosts see the wrong version string even after the correct tag is live. This PR closes that gap so the v0.5.1 tag can be cut cleanly.
