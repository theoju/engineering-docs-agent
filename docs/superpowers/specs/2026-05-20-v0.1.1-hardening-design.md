# v0.1.1 Hardening Design

**Goal:** Close all 40 reviewer-surfaced findings from the v0.1.0 cross-phase review so the engineering-docs-agent is safe to dogfood beyond the original ADIS pilot.

**Architecture:** Single feature branch (`feat/v0.1.1-hardening`) off `8d6d0d9`. Five sequential phases land on the same branch and merge as one PR. Phase 1 builds typed boundaries and runtime validation infrastructure; Phases 2–5 wire that foundation through every existing pipeline, then close test gaps and normalize cleanup items.

**Tech stack:** Python 3.11+, stdlib `dataclasses`, existing `jsonschema` dep, existing `pytest` harness. No new runtime dependencies.

---

## Background

v0.1.0 shipped at commit `1f4563c` (critical post-review hardening) plus `8d6d0d9` (regression tests for lint cleanup and verify-runner failure paths). 64 tests passing. A fresh code-reviewer pass at `8d6d0d9` surfaced 40 non-blocking findings across 6 categories. This spec consolidates those 40 findings, sets the architectural policies needed to fix them coherently, and lays out the five-phase work plan.

---

## Design decisions (locked)

These choices were made during brainstorming and underlie every fix below. Change one and large parts of the spec change with it.

1. **Scope: all 40 findings.** No deferral to v0.1.2.
2. **Validation policy: mixed.** Config and state validation failures are hard-fails (exit 2 with a clear message — these are operator-controlled). Subagent output validation failures are soft-fails (logged to `partial_reasons`, the run continues with whatever else it can do — LLM responses are imperfect by nature).
3. **Type library: stdlib `dataclasses` + `jsonschema`.** No Pydantic. The schemas are the source of truth for shape; dataclasses are the typed Python view used by orchestrator code. A small parser bridges the two.
4. **Release shape: single PR.** All ~40 fixes land on `feat/v0.1.1-hardening` and merge as one reviewable PR. Same flow as v0.1.0.
5. **gh testing strategy: recorded fixtures + injectable client.** Wrap every gh call in a `GhClient` class. Tests inject a `FakeGhClient` that returns canned JSON from `tests/gh_fixtures/`.
6. **Sequencing: foundation-first.** Phase 1 builds infrastructure (schemas, dataclasses, `GhClient`, validated loaders, partial-run helper) before any pipeline behavior changes. Phases 2–5 stack on the foundation.
7. **Stale-state heuristic: time-based.** If `current_run.started_at` is older than 24h on the next orchestrator run, treat the run as abandoned: clear `current_run`, log `stale_current_run_cleared` as a partial reason, and start fresh. No attempts counter, no schema change.
8. **Branch naming: hour-precision.** `docs-agent/{YYYY-MM-DDTHH}` replaces `docs-agent/{YYYY-MM-DD}`. Same-day reruns get distinct branches; same-hour reruns still append-commit to the same branch.
9. **stub_redirect config grammar: rule-side coercion.** Keep `tier1: default` (string) as the binary on/off signal. The stub_redirect rule script reads optional paths from a sibling `lint.stub_paths` key instead of nesting under `tier1`. Backward-compatible.

## The 40 findings (inventory at `8d6d0d9`)

Severity tags: HIGH = blocking-class semantics surviving, MED = silent-failure or hidden-coupling risk, LOW = polish/consistency.

### Category A — Contract mismatches (orchestrator vs. agent .md)

- **A1 [HIGH]** `source-collector` receives no `jira` input key. Agent contract specifies `jira: { enabled, project_keys, base_url }`; orchestrator never constructs it. (`scripts/orchestrator_runner.py:100-109`)
- **A2 [HIGH]** `jira_issues` from source-collector are never forwarded to `pr-summarizer`. Orchestrator passes `jira_context: []` unconditionally. (`scripts/orchestrator_runner.py:114-122`)
- **A3 [MED]** `page-author` receives `voice_samples: []` unconditionally. Voice consistency is never actually applied. (`scripts/orchestrator_runner.py:147`)
- **A4 [MED]** `content-validator` receives `voice_samples: []` unconditionally. Tier-2 voice_consistency check is effectively disabled. (`scripts/orchestrator_runner.py:172`)
- **A5 [MED]** `pr_id` format mismatch between orchestrator-constructed dismissed-flag key (`{owner}/{name}#{n}`) and gap-detector echo (`x/y#1` in fixtures). Dismissed-flag check is effectively dead.
- **A6 [MED]** No pre-filter against `agent_editable_paths` before page-author dispatch. A `page_hint: "../../etc/passwd.md"` would have its parent directory created before any safety check.

### Category B — Error handling & runtime safety

- **B1 [HIGH]** `open_or_append_pr` parses PR number with `int(r.stdout.strip().split("/")[-1])`. Raises uncaught `ValueError` on unexpected gh output. (`scripts/orchestrator_runner.py:378`)
- **B2 [HIGH]** `dispatch_subagent` production path calls `json.loads(r.stdout)` with no `JSONDecodeError` guard. Empty stdout or non-JSON CLI output crashes the run. (`scripts/orchestrator_runner.py:67`)
- **B3 [MED]** `verify_runner` crash during `publish-verifier` dispatch leaves state.json un-updated; `current_run` persists indefinitely.
- **B4 [MED]** `git push` failure raises `CalledProcessError` uncaught after state.json has been written with `pr_number: null`. Partial-run signal is lost from the caller's perspective.
- **B5 [MED]** `existing_pr_for_branch` calls `json.loads(r.stdout or "[]")` — guards empty stdout but not non-JSON gh output.
- **B6 [MED]** Empty-PR-list runs still write a `## <timestamp>` header with no bullets to `whats_new_file`. File slowly fills with empty entries.
- **B7 [MED]** `source-collector` `error` / `partial` responses silently ignored. A rate-limited run that returned 0/5 PRs looks like a clean 0-PR run.
- **B8 [MED]** `pr-summarizer` `error` responses appended to summaries list and consumed via `.get("doc_targets", [])`. Silently produces no output, no partial signal.
- **B9 [LOW]** Commit step uses `check=False`. If no files staged, exits non-zero (swallowed) and push attempts an empty branch.

### Category C — Schema & state consistency

- **C1 [HIGH]** Schemas in `templates/*.schema.json` are never enforced at load time. Misconfigured `config.yml` fails deep in the pipeline with a `KeyError`.
- **C2 [LOW]** `dismissed_gap_flags` schema declares `additionalProperties: string` but orchestrator never writes to this key — read-only, hand-edited by operators. Schema description is missing.
- **C3 [MED]** `current_run.pr_number` in state is never cross-checked against `verify_runner`'s `--pr-number` CLI argument. Possible silent mismatch.

### Category D — Dead code & structural

- **D1 [HIGH]** `scripts/archive_indexes.py` exists, is tested in isolation, never called by the orchestrator.
- **D2 [LOW]** Docusaurus paths in `setup_discover.py` and the schema enum are dead for v0.1 — `framework_build.py` skips them.
- **D3 [MED]** `lint_runner.py` `any_block_failed` aggregation only catches `severity: block`. Warn-rule failures (`reading_grade`, `duplicate_content`) silently return exit 0.
- **D4 [LOW]** `duplicate_content.py` exits `2` on failure; convention is `1`.
- **D5 [LOW]** `reading_grade.py` exits `2` on failure; convention is `1`.
- **D6 [LOW]** `diagrams.py` does not guard `path.exists()`; raises `FileNotFoundError` instead of returning a structured result.
- **D7 [MED]** `stub_redirect.py` reads `config.get("lint", {}).get("tier1", {}).get("stub_paths", []) if isinstance(tier1, dict) else []`. When `tier1: default` (string) — the production config — `stub_paths` is always empty and the rule silently no-ops.

### Category E — Test gaps

- **E1 [MED]** No test for zero-PR run path.
- **E2 [MED]** No test for multi-PR / multi-lens authoring batching.
- **E3 [HIGH]** No test for `JSONDecodeError` in production dispatch path.
- **E4 [MED]** No test for `open_or_append_pr` / gh error paths.
- **E5 [MED]** No end-to-end `gh pr view` fixture for verify_runner production path.
- **E6 [MED]** No test for source-collector `error` / `partial` response propagation.
- **E7 [LOW]** `framework_build.py` real-mkdocs success/failure paths untested.
- **E8 [LOW]** `lint_runner.py` error-injection paths (missing script, empty output) untested.
- **E9 [MED]** `stub_redirect` rule never tested with `tier1: default` (the production config).
- **E10 [LOW]** `setup_discover.detect_jira_hint` not directly tested with workflow-file fixtures.

### Category F — Hidden coupling & partial-run inconsistencies

- **F1 [MED]** `source-collector` `partial: true` doesn't trip orchestrator's partial flag (cross-references B7).
- **F2 [MED]** `verify_runner` crash leaves stale `current_run` forever; no TTL or staleness check.
- **F3 [MED]** `branch_name(now_iso)` returns date-only. Same-day reruns share a branch and `git checkout -B` clobbers prior work.
- **F4 [LOW]** Empty parent directories left behind after `unlink` cleanup.
- **F5 [LOW]** Two PRs targeting the same `(lens, page_hint)` produce two `page-author` calls; second overwrites first without merging.

### 1b. `scripts/contracts.py`

**New module.** Single file with all subagent dataclasses and the validator helper.

```python
from __future__ import annotations
from dataclasses import dataclass
from pathlib import Path
from typing import Any, TypeVar
import json
import jsonschema

T = TypeVar("T")
SCHEMAS_DIR = Path(__file__).parent.parent / "agents" / "schemas"


@dataclass(frozen=True)
class SourceCollectorResult:
    prs: list[dict]
    jira_issues: list[dict]
    error: str | None = None
    partial: bool = False


@dataclass(frozen=True)
class PrSummary:
    pr_number: int
    what_changed: str
    why: str
    breaking: bool
    doc_targets: list[dict]
    notes: str | None = None
    error: str | None = None


# ... (one dataclass per subagent)


def validate_and_parse(name: str, raw: dict) -> tuple[Any | None, list[str]]:
    """Validate raw subagent output against its schema; return typed result or errors.

    Returns (dataclass_instance, []) on success.
    Returns (None, [error_messages]) on validation failure (soft-fail policy).
    """
    schema_path = SCHEMAS_DIR / f"{name.replace('-', '_')}.schema.json"
    if not schema_path.exists():
        return None, [f"schema_missing: {name}"]
    schema = json.loads(schema_path.read_text())
    try:
        jsonschema.validate(raw, schema)
    except jsonschema.ValidationError as e:
        return None, [f"schema_invalid: {name}: {e.message}"]
    return _DATACLASS_BY_NAME[name](**_dataclass_kwargs(name, raw)), []
```

The `_DATACLASS_BY_NAME` dict and the `_dataclass_kwargs` filter keep field selection in one place. Optional fields default to `None` or sane defaults so partial subagent output still parses.

### 1c. `scripts/gh_client.py`

**New module.** A small class plus a fake for tests.

```python
from __future__ import annotations
from dataclasses import dataclass
import json
import re
import subprocess
from pathlib import Path


@dataclass
class GhResult:
    ok: bool
    value: object | None = None
    error: str | None = None


class GhClient:
    """Centralized gh CLI wrapper. Every gh call goes through here."""

    def __init__(self, repo_root: Path) -> None:
        self._cwd = repo_root

    def pr_view_files(self, pr_number: int) -> GhResult:
        return self._run_json(
            ["gh", "pr", "view", str(pr_number), "--json", "files"],
            extract=lambda d: [f["path"] for f in d.get("files", [])],
        )

    def pr_list_for_branch(self, branch: str) -> GhResult:
        return self._run_json(
            ["gh", "pr", "list", "--head", branch, "--state", "open",
             "--json", "number", "-L", "1"],
            extract=lambda d: (d[0]["number"] if d else None),
        )

    def pr_create(self, branch: str, title: str, body: str) -> GhResult:
        try:
            r = subprocess.run(
                ["gh", "pr", "create", "--head", branch,
                 "--title", title, "--body", body],
                cwd=self._cwd, capture_output=True, text=True,
            )
        except FileNotFoundError:
            return GhResult(ok=False, error="gh_not_installed")
        if r.returncode != 0:
            return GhResult(ok=False, error=f"gh_pr_create_failed: {r.stderr[:200]}")
        return self._parse_pr_create_output(r.stdout, branch)

    def _parse_pr_create_output(self, stdout: str, branch: str) -> GhResult:
        # Strategy 1: int from last URL segment
        last = stdout.strip().split("/")[-1] if stdout.strip() else ""
        if last.isdigit():
            return GhResult(ok=True, value=int(last))
        # Strategy 2: regex /pull/(\d+)
        m = re.search(r"/pull/(\d+)", stdout)
        if m:
            return GhResult(ok=True, value=int(m.group(1)))
        # Strategy 3: ask gh for the number we just (presumably) created
        return self.pr_list_for_branch(branch)

    def _run_json(self, cmd, *, extract):
        try:
            r = subprocess.run(cmd, cwd=self._cwd,
                               capture_output=True, text=True, check=True)
        except FileNotFoundError:
            return GhResult(ok=False, error="gh_not_installed")
        except subprocess.CalledProcessError as e:
            return GhResult(ok=False, error=f"gh_failed: {e.stderr[:200]}")
        try:
            data = json.loads(r.stdout or "null")
        except json.JSONDecodeError as e:
            return GhResult(ok=False, error=f"gh_bad_json: {e}")
        return GhResult(ok=True, value=extract(data))


class FakeGhClient:
    """Test injection point. Constructor takes canned responses keyed by method."""

    def __init__(self, *, pr_view_files=None, pr_list_for_branch=None,
                 pr_create=None) -> None:
        self._canned = {
            "pr_view_files": pr_view_files,
            "pr_list_for_branch": pr_list_for_branch,
            "pr_create": pr_create,
        }
        self.calls: list[tuple[str, tuple]] = []

    def pr_view_files(self, pr_number):
        self.calls.append(("pr_view_files", (pr_number,)))
        return self._canned["pr_view_files"] or GhResult(ok=True, value=[])

    def pr_list_for_branch(self, branch):
        self.calls.append(("pr_list_for_branch", (branch,)))
        return self._canned["pr_list_for_branch"] or GhResult(ok=True, value=None)

    def pr_create(self, branch, title, body):
        self.calls.append(("pr_create", (branch, title, body)))
        return self._canned["pr_create"] or GhResult(ok=True, value=1)
```

### 1d. `scripts/state_io.py`

**New module.** Holds config/state loaders with schema validation AND the `add_partial` helper (1d+1e merged per Section 1 ranking).

```python
from __future__ import annotations
from pathlib import Path
from typing import Any
import json
import jsonschema
import yaml

TEMPLATES_DIR = Path(__file__).parent.parent / "templates"


class ConfigError(Exception):
    """Raised when config.yml fails schema validation. Hard-fail."""


class StateError(Exception):
    """Raised when state.json fails schema validation. Hard-fail."""


def load_config_validated(path: Path) -> dict[str, Any]:
    if not path.exists():
        raise ConfigError(f"config not found: {path}")
    raw = yaml.safe_load(path.read_text()) or {}
    schema = json.loads((TEMPLATES_DIR / "config.schema.json").read_text())
    try:
        jsonschema.validate(raw, schema)
    except jsonschema.ValidationError as e:
        raise ConfigError(f"config invalid at {e.json_path}: {e.message}") from e
    return raw


def load_state_validated(path: Path) -> dict[str, Any]:
    raw = json.loads(path.read_text()) if path.exists() else {"version": "1"}
    schema = json.loads((TEMPLATES_DIR / "state.schema.json").read_text())
    try:
        jsonschema.validate(raw, schema)
    except jsonschema.ValidationError as e:
        raise StateError(f"state invalid at {e.json_path}: {e.message}") from e
    return raw


def add_partial(state: dict, reason: str) -> None:
    """Mark current_run as partial and append the reason. Idempotent on reason."""
    if "current_run" not in state:
        state["current_run"] = {"partial": True, "partial_reasons": []}
    cr = state["current_run"]
    cr["partial"] = True
    cr.setdefault("partial_reasons", [])
    if reason not in cr["partial_reasons"]:
        cr["partial_reasons"].append(reason)


def cleanup_empty_parents(path: Path, *, until: Path) -> None:
    """Walk up from path.parent, removing empty dirs, stopping at `until`."""
    until_resolved = until.resolve()
    current = path.parent.resolve()
    while current != until_resolved and until_resolved in current.parents:
        try:
            current.rmdir()
        except (OSError, FileNotFoundError):
            return
        current = current.parent


def load_voice_samples(repo_root: Path, config: dict) -> list[dict]:
    """Read voice samples per config.voice.sample_paths plus host CLAUDE.md.

    Returns list of {path, content} dicts, total content capped at ~20KB.
    """
    samples: list[dict] = []
    total = 0
    cap = 20_000
    sources: list[Path] = []
    voice_cfg = config.get("voice", {}) or {}
    for rel in voice_cfg.get("sample_paths", []) or []:
        sources.append(repo_root / rel)
    claude_md = repo_root / "CLAUDE.md"
    if claude_md.exists():
        sources.append(claude_md)
    for src in sources:
        if not src.exists() or not src.is_file():
            continue
        try:
            text = src.read_text()
        except (OSError, UnicodeDecodeError):
            continue
        snippet = text[: max(0, cap - total)]
        if not snippet:
            break
        samples.append({"path": str(src.relative_to(repo_root)), "content": snippet})
        total += len(snippet)
        if total >= cap:
            break
    return samples
```

### 2f. archive_indexes integration (D1)

After page authoring (whether or not validation blocked items), check each configured lens for an `archive_index: true` extension flag in `config.docs.lens_paths`:

```yaml
# Extended config grammar (backward-compatible):
docs:
  lens_paths:
    core: docs/site-src/core
    archive:
      path: docs/site-src/archive
      archive_index: true
```

A new helper `resolve_lens(config, lens) -> tuple[Path, dict]` (added to `state_io.py`) normalizes both forms — returns `(Path(value), {})` for the string form and `(Path(value["path"]), {k: v for k, v in value.items() if k != "path"})` for the dict form. Every existing call site `config["docs"]["lens_paths"][lens]` becomes `path, lens_opts = resolve_lens(config, lens)`. When `lens_opts.get("archive_index")` is true, after page authoring runs:

```python
import archive_indexes
archive_indexes.regenerate(repo_root / path)
```

`archive_indexes.regenerate(root: Path)` is the new public entrypoint (the existing `main()` stays for CLI use). Empty-subdir case emits `# {name}\n\n_No entries yet._\n` instead of trailing empty bullets.

## Phase 3 — Error handling & runtime safety

### 3a. Production subagent dispatch hardening (B2, E3)

`dispatch_subagent` production branch:

```python
def dispatch_subagent(name: str, inputs: dict, *, dry_run_dir: Path | None) -> dict | None:
    if dry_run_dir is not None:
        fixture = dry_run_dir / f"fake_{name.replace('-', '_')}.json"
        if not fixture.exists():
            return None
        return load_json(fixture)
    payload = json.dumps(inputs)
    try:
        r = subprocess.run(
            ["claude", "agent", name, "--input", payload],
            capture_output=True, text=True, check=False,
        )
    except FileNotFoundError:
        return None  # claude CLI not installed
    if r.returncode != 0:
        return None
    stdout = r.stdout.strip()
    if not stdout:
        return None
    try:
        return json.loads(stdout)
    except json.JSONDecodeError:
        return None
```

Return type changes from `dict` to `dict | None`. Caller is `validate_and_parse(name, raw or {})` which already handles `{}` correctly (returns `(None, [schema_invalid: ...])`). All call sites get the same uniform pattern:

```python
raw = dispatch_subagent(name, inputs, dry_run_dir=dry_run_dir)
typed, errors = validate_and_parse(name, raw or {})
if typed is None:
    for err in errors:
        add_partial(state, f"{name.replace('-', '_')}_invalid: {err}")
    continue  # or whatever the loop body's no-op fallback is
```

```python
def open_or_append_pr(repo_root, gh, *, branch, now_iso, partial, partial_reasons):
    # git checkout/add/commit/push unchanged
    existing = gh.pr_list_for_branch(branch)
    if not existing.ok:
        return None  # caller logs via partial_reasons
    if existing.value is not None:
        return existing.value
    title = f"docs(agent): run {now_iso}" + (" (partial)" if partial else "")
    body = ("WARNING — Partial run — " + "; ".join(partial_reasons)) if partial else "docs-agent run"
    created = gh.pr_create(branch, title, body)
    if not created.ok:
        return None
    return created.value
```

## Cross-cutting workflow

- **Branch:** `feat/v0.1.1-hardening` off `8d6d0d9`. Merge to `main` (or `feat/v0.1-implementation` if v0.1 isn't yet merged at PR time) as one PR.
- **Per-phase checkpoint:** full pytest suite green before starting the next phase. If a phase introduces a regression, fix in that phase before proceeding.
- **Final gates before merge PR:**
  1. `python3 -m pytest` clean green.
  2. `/simplify` pass on the full diff (`git diff main...HEAD`).
  3. `/requesting-code-review` with this spec doc as input.
  4. All blocking review comments resolved (non-blocking may be deferred to v0.1.2 with explicit notes in the CHANGELOG).
- **Model selection per phase:**
  - Phase 1 (foundation): Sonnet — mechanical but type-design judgment matters.
  - Phase 2 (contracts): Sonnet — coordinated edits across multiple modules.
  - Phase 3 (errors): Sonnet — error-handling judgment.
  - Phase 4 (tests): Sonnet — test design.
  - Phase 5 (cleanup): Haiku — almost entirely mechanical.
